# Miracle Photography Studio

> A bespoke, high-end portfolio website for **Miracle Photography Studio** (Laurelton, NY). Built with Next.js 14+ (App Router), TypeScript, Tailwind CSS, and Framer Motion. Replaces the outdated Zenfolio template with an Awwwards-caliber digital atelier.

---

## 📸 Brand Overview

- **Studio Name**: Miracle Photography Studio
- **Address**: 227-12A Merrick Blvd, Laurelton, NY 11413, United States
- **Direct Line**: (718) 341-7376
- **Aesthetic**: Moody, dark cinematic hero sections contrasted with soft neutral gallery backgrounds, large editorial serif typography (*Playfair Display*), clean sans body (*Plus Jakarta Sans*), and generous whitespace.

---

## 🚀 Key Features

### 1. Home (`/`)
- **100vh / 100svh Above-The-Fold Hero**: Full-bleed rotating carousel calibrated to guarantee complete visibility of the headline, dynamic eyebrow tag, subtext, both CTA buttons (*"View Gallery"* and *"Book a Session"*), and bottom navigation bar without scrolling on initial page load.
- **Dedicated Eyebrow Label**: Dynamic category + location (`WEDDINGS & CEREMONIES • Hudson Valley, NY`) positioned cleanly above the headline.
- **Studio Heritage Teaser**: 15-year Laurelton, NY milestone credentials, 1,200+ weddings/events, and client praise metrics.
- **Featured Collections Showcase**: 4-card editorial preview with instant Lightbox access.
- **Testimonial Strip**: Quotes from wedding couples, milestone families, and Manhattan gala organizers.

### 2. Curated Gallery (`/gallery`)
- **Filter Tabs**: Real-time filtering across *Weddings*, *Baby Portraits*, *Events*, and *Editorial Portraits* with count badges.
- **Responsive Masonry Grid**: High-resolution photography with lazy loading and Next.js Image optimization.
- **Fullscreen Lightbox**: Keyboard arrow navigation (`←`, `→`, `Esc`), shot details, and a direct *"Inquire About This Style"* booking trigger.

### 3. Client Login / Gallery Portal (`/client-portal`)
- **Pixieset & Pic-Time Styled Private Access**: Centered glassmorphic card over ambient photography blur with floating-label fields.
- **Interactive Demo Unlock**: Instant unlock feature to experience a private client gallery (*The Thompson Wedding at Oheka Castle*) with favorite heart toggles, high-res downloads, and ZIP archive simulation.

### 4. Contact Us (`/contact`)
- **Two-Column Editorial Layout**:
  - **Left**: Studio details, hours, custom *"Like Us on Facebook"* and Instagram links, and an **interactive Google Maps embed** for 227-12A Merrick Blvd, Laurelton, NY.
  - **Right**: Modern inquiry form with floating labels and submission feedback modal.

### 5. Global Polish
- **Bespoke Vector SVG Logo**: Optical lens mark with multi-stop radial gradients, aperture diaphragm blades, and glass reflection highlights.
- **Sticky Glass Navbar**: Blur backdrop with smooth mobile drawer and one-click refresh to home.
- **Multi-Column Editorial Footer**: Complete contact directory, studio hours, and zero third-party platform branding.

## 🛠️ Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Typography**: Google Fonts (*Playfair Display* & *Plus Jakarta Sans*)
- **Icons**: Custom SVG & Lucide React
- **Animations**: CSS transitions & Framer Motion

## 💻 Getting Started

```bash
# Clone the repository
git clone https://github.com/technotecksystems/miraclestudio.git

# Navigate into the project
cd miraclestudio

# Install dependencies
npm install

# Run the development server
npm run dev

# Or build and run for production
npm run build
npm run start -- -p 2867
```
